# Face Attendance System

## Overview
A Python-based student attendance system that uses
face detection and face recognition through a webcam.

## Technologies
- Python
- OpenCV
- NumPy
- Haar Cascade
- LBPH Face Recognition

## Features
- Face detection using a webcam
- Recognition of registered students
- Automatic attendance marking
- Attendance records stored in CSV files

## Project Files
- attendance_system.py
- camera_test.py
- capture_faces.py

## How to Run

1. Install Python.
2. Install the required libraries.
3. Register student faces.
4. Run the attendance system.

## Privacy
Do not upload real student face images or
private attendance records to GitHub.
